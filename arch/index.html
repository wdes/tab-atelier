tab-atelier Arch Linux repo

A signed-optional pacman repository (rolling; newest build wins). Add it to /etc/pacman.conf:

[tab-atelier]
SigLevel = Optional TrustAll
Server = https://deb.tab-atelier.wdes.eu/arch

Then install (the two packages conflict — pick one):

sudo pacman -Sy tab-atelier            # desktop GUI
sudo pacman -Sy tab-atelier-headless   # display-less daemon
Prefer building from source? The AUR-style PKGBUILD lives in packaging/arch/.
